# NOVA KAI — Creator Link Microsite

A premium editorial link-in-bio experience for a fictional multi-content creator. Designed as a richer alternative to a standard list of social links.

## Features

- Magazine-inspired responsive hero
- Swipeable and draggable content carousel
- Interactive bento-style link grid
- Podcast mini-player
- Upcoming live countdown section
- Share, reminder and notification interactions
- Responsive mobile layout
- Optimized original WebP imagery
